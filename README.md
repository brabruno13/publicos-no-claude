# Públicos no Claude

O Claude monta o público do seu anúncio no Meta Ads pelo método da DHG: combinação de interesses com **E** pra pegar quem tem interesse de verdade, e **camada de poder aquisitivo** quando o produto é caro.

Você escreve:

> Monta os públicos da minha construtora de alto padrão em São Paulo.

E o Claude:
1. faz as perguntas certas (ticket, cliente, região, objetivo);
2. pesquisa os interesses reais na Meta e monta 3 opções: aberta, equilibrada e restrita;
3. mostra o tamanho estimado de cada público;
4. cria o conjunto de anúncios **pausado** na sua conta, pra você revisar e ativar.

## Caso real

Construtora de alto padrão, campanha da DHG: **R$ 1.158 investidos, 257 mensagens e 77 visitas ao plantão de vendas.**

Público: Imóveis residenciais **E** Investimento imobiliário **E** (usuários de iPhone 15 ou mais novo, viajantes internacionais).

Resultado varia de acordo com o negócio, a oferta, o criativo e a verba.

## Instalação em 1 passo

Abra o Claude Code e cole:

```
Instala pra mim o https://github.com/<SEU-USUARIO>/publicos-no-claude. Lê o INSTALL.md e segue os passos. Me pede o token da Meta quando precisar.
```

O que você vai precisar:
- Claude Code;
- uma conta de anúncios na Meta;
- um token da Meta (o Claude te guia pra gerar).

## O que tem aqui
- `skills/publicos-no-claude/`: a skill com o método.
- `INSTALL.md`: o passo a passo que o Claude Code segue pra instalar.

## Créditos
A conexão com a Meta usa o [byadsco/meta-ads-mcp](https://github.com/byadsco/meta-ads-mcp), projeto de código aberto com licença MIT. Este repositório não tem ligação com a Meta.
